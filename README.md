# 📌 Introduction

The **Heart Disease Prediction System** is a Machine Learning project developed using **Python** and **Scikit-learn** to predict whether a patient is likely to have heart disease based on medical attributes.

This project compares multiple Machine Learning classification algorithms and identifies the best-performing model based on prediction accuracy.

The project demonstrates the practical implementation of:

- Machine Learning
- Data Analysis
- Data Visualization
- Classification Algorithms
- Predictive Analytics
- Model Evaluation

# 📂 Dataset Information

The dataset contains **303 patient records** with **13 medical features**.

### Dataset Features

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- Slope
- CA
- Thal

### Target Variable

- **0 → No Heart Disease**
- **1 → Heart Disease**
